# Медицинский диагностический центр

Веб-сайт для компании медицинской диагностики. Проект предоставляет полный функционал для управления услугами, врачами, записями на прием и личными кабинетами пациентов. Реализован на Django с использованием Bootstrap 5 для адаптивного интерфейса, упакован в Docker-контейнеры для простого развертывания.

## Технологии

*   **Backend:** [Django 6.0.2](https://www.djangoproject.com/) (Python 3.12+)
*   **База данных:** [PostgreSQL 15](https://www.postgresql.org/)
*   **ORM:** Встроенная ORM Django (без прямых SQL-запросов)
*   **Аутентификация:** Встроенная система `django.contrib.auth`
*   **Формы:** Django Forms с валидацией данных
*   **Шаблонизатор:** Django Templates + [Bootstrap 5](https://getbootstrap.com/) для стилизации
*   **Контейнеризация:** [Docker](https://www.docker.com/) и [Docker Compose](https://docs.docker.com/compose/)
*   **Тестирование:** `pytest`, `pytest-django`, `pytest-cov` (покрытие кода 96%)
*   **Качество кода:** `flake8` (PEP8), `black`, `isort`
*   **Контроль версий:** Git

## Функционал сайта

Проект полностью реализует требования для медицинского диагностического центра:

1.  **Главная страница**: Описание компании, перечень популярных услуг, контактная информация в подвале.
2.  **Страница "О компании"**: История, миссия, ценности и полный список врачей.
3.  **Страница услуг**: Список всех услуг с ценами, детальная страница каждой услуги, поиск.
4.  **Страница "Контакты"**: Адрес, карта проезда, телефоны, email и форма обратной связи.
5.  **Личный кабинет**: Регистрация и авторизация, запись на прием, просмотр истории записей и результатов диагностики.
6.  **Админ-панель Django**: Управление пользователями, услугами, врачами, записями и контентом.

## Установка и запуск

### Требования

*   Установленные [Docker](https://docs.docker.com/get-docker/) и [Docker Compose](https://docs.docker.com/compose/install/).
*   (Опционально, для разработки) Python 3.12+ и [Poetry](https://python-poetry.org/).

### Запуск в Docker (рекомендуемый способ)

1.  **Клонируйте репозиторий:**
    ```
    git clone <ссылка-на-твой-репозиторий>
    cd medical-diagnostics-company
    ```
2.  **Создайте файл .env из примера и заполните его:**
    ```
    cp .env.sample .env
    # Отредактируйте .env, указав свои данные (SECRET_KEY, настройки БД и почты)
    # Для быстрого старта можно оставить значения по умолчанию.
    ```
3. **Запустите контейнеры:**
    ```
    docker-compose up -d --build
    ```
    Эта команда соберет образы и запустит контейнеры Django и PostgreSQL в фоне.

4. **Примените миграции (если не применились автоматически):**
    ```
    docker-compose exec web python manage.py migrate
    ```
5. **Создайте суперпользователя для доступа в админку:**
    ```
    docker-compose exec web python manage.py createsuperuser
    ```
6. **Откройте сайт в браузере:**
    * Сайт: [http://localhost:8000](http://localhost:8000)
    * Админка: [http://localhost:8000/admin](http://localhost:8000/admin)

## Использование
После запуска сайта вы можете:
  * **Как посетитель:** Просматривать информацию об услугах, врачах, контакты.
  * **Как зарегистрированный пользователь:** Войти в личный кабинет, записаться на прием, просмотреть историю.
  * **Как администратор:** Войти в /admin и управлять всем контентом (услуги, врачи, записи).

## Тестирование
Проект покрыт юнит-тестами с общим покрытием 96% (выше требуемых 75%). Для тестирования используется pytest.
Запуск всех тестов:
```
# Через Docker
docker-compose exec web pytest

# Локально
poetry run pytest
```

### Запуск с отчетом о покрытии:
```
pytest --cov=. --cov-report=html
# После выполнения откройте htmlcov/index.html в браузере.
```

### Проверка стиля кода (PEP8):
```
flake8 .
```
